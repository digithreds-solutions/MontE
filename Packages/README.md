# Mont-E Distribution Packages (v2.0.0)

This directory holds local compiled installer DMGs for Mont-E.
Official release binaries and release notes are hosted on [GitHub Releases](https://github.com/digithreds-solutions/MontE/releases).

### Built Packages in this Repository:
- **`Monte-2.0.0.dmg`**: Mont-E v2.0.0 — Wi-Fi Diagnostics, Multi-Volume APFS, P/E-Core Cluster breakdown, GPU Telemetry, Watchdog Alerts & Sparklines.
- **`Monte-1.0.0.dmg`**: Mont-E v1.0.0 — Initial Release with Hardware Stats, Battery Preservation & SSD Optimizer.
